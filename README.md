# Syed Mujtaba Abbas — Sovereign Kinetic Editorial Portfolio

An Awwwards-inspired, 3D-powered developer portfolio rebuilt for **Syed Mujtaba Abbas** ([https://www.syedmujtabaabbas.xyz/](https://www.syedmujtabaabbas.xyz/)).

## Architectural Highlights

- **Centralized Verified Data Layer (`src/data/portfolioData.ts`):** Every project, skill category, experience milestone, academic foundation, AI workflow node, service offering, and social/contact channel is stored in one strongly-typed TypeScript configuration file so you can update content without touching presentation components.
- **Obsidian & Metallic Gold Design System (`src/index.css`):** Built strictly around `#080808` (Obsidian Black), `#121212` (Deep Charcoal), `#D4AF37` (Warm Metallic Gold), `#F1DFA6` (Soft Champagne), `#F5F2EA` (Off-White Typography), and `#929292` (Muted Grey).
- **Interactive Three.js Centerpiece (`src/components/HeroScene.tsx`):** Procedural metallic gold **"Astrolabe Computational Core"** with counter-rotating gimbal rings, orbital telemetry satellites, pointer-reactive gold particle field, interactive geometry mode switching (`Astrolabe Core`, `Neural Lattice`, `Orbital Telemetry`), offscreen `IntersectionObserver` pausing, and automatic WebGL fallback.
- **Authentic Portrait Composition (`src/components/AboutSection.tsx`):** Preserves `/syed-mujtaba-abbas-software-engineer-karachi.png` from the live website with studio gold rim lighting, interactive 3D card tilt, and verified provenance metadata.
- **10-Domain Technical Universe (`src/components/SkillsSection.tsx`):** Interactive SVG Orbital Constellation + searchable 10-domain matrix mapping verified skills directly to real repositories and roles (zero fabricated proficiency percentages).
- **Selected Projects & 7-Point Case Studies (`src/components/ProjectsGallery.tsx`):** Asymmetric editorial gallery featuring all 6 projects from `syedmujtabaabbas.xyz` (`EduGenius`, `SetupCI`, `KarachiGum`, `Ayesha Fashion`, `Norvia`, `Fuji Fenix Elevator`) plus 4 verified repositories from `github.com/syed-mujtaba-stack` (`WhatsApp AI Agent Platform`, `LeadHunter v2`, `MJ FTE CLI Agent`, `ClipCompress`), complete with interactive 7-point Case Study modals and honest audit notes.
- **Agentic AI & Automation Showcase (`src/components/AIAgentVisualization.tsx`):** Interactive node-and-connection pipeline simulator with animated gold data-flow pulses, step-by-step execution inspector, and direct links to real AI repositories.
- **SEO & Discoverability (`index.html`, `public/robots.txt`, `public/sitemap.xml`):** Canonical URL (`https://www.syedmujtabaabbas.xyz/`), Open Graph & Twitter cards, and JSON-LD `Person` + `WebSite` structured data.
